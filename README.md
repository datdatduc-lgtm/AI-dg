# AI-dg

AI-dg is a portable Agent Skill project for construction/interior drawing estimation.

The first milestone focuses on a safe, auditable workflow:

**PDF → page extraction/rendering → structured items → BOM → Excel**

The skill is designed to be usable by both Codex and OpenCode through the shared Agent Skills location `.agents/skills/`.

> Status: bootstrap repository. V0.1 implementation is developed on a feature branch before review/merge.
